# FutureClient

A high-performance, Lunar Client-inspired PvP client for Minecraft 1.20.1 using Fabric.

## Features

### HUD Modules
- **Keystrokes** - Display WASD and mouse button presses
- **CPS Counter** - Track your clicks per second
- **FPS Display** - Monitor your frame rate
- **Ping Display** - Show your connection latency
- **Coordinates** - Display your current position

### PvP Modules
- **Toggle Sprint** - Automatically sprint while moving
- **Old Animations** - 1.8.9-style combat animations
- **Custom Crosshair** - Customizable crosshair

### Render Modules
- **Zoom** - Smooth OptiFine-style zoom
- **Particle Control** - Reduce particle spam
- **Entity Culling** - Improve FPS by not rendering off-screen entities

## Installation

1. Download and install [Fabric Loader](https://fabricmc.net/use/)
2. Download [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download FutureClient from [Releases](https://github.com/yourusername/futureclient/releases)
4. Place both JAR files in your `.minecraft/mods` folder
5. Launch Minecraft 1.20.1 with the Fabric profile

## Usage

- Press **RIGHT SHIFT** to open the client GUI
- Toggle modules on/off
- Configure keybinds and settings
- Enjoy smooth PvP gameplay!

## Building from Source
```bash
git clone https://github.com/yourusername/futureclient.git
cd futureclient
./gradlew build
```

The compiled JAR will be in `build/libs/`
